# Álomváros Szimulátor

![verzió](https://img.shields.io/badge/verzió-2.0.0-blue)
![Python](https://img.shields.io/badge/Python-3.8+-green)

Üdvözöllek az **Álomváros Szimulátorban**! Ez egy városépítő szimulációs játék, ahol megtervezheted és felépítheted a saját virtuális városodat.

## Mi ez?

Ebben a játékban:
- **Építkezhetsz**: Hozz létre lakóházakat, boltokat, ipari létesítményeket.
- **Menedzselhetsz**: Gondoskodj a lakosságról, fejleszd a szolgáltatásokat (oktatás, egészségügy).
- **Figyelhetsz**: Kövesd a város pénzügyeit és a lakók elégedettségét.
- **Fejlődhetsz**: Hozz döntéseket fordulóról fordulóra, és nézd, hogyan alakul a városod sorsa.

## Telepítés

1.  **Szerezd be a kódot:**
    ```bash
    git clone https://github.com/futozs/MiskolcEgyetem_sim-city
    cd MiskolcEgyetem_sim-city
    ```
2.  **Telepítsd a szükséges csomagokat:**
    *   Győződj meg róla, hogy Python 3.8 vagy újabb verzió van telepítve.
    *   Futtasd a következőt a projekt mappájában:
        ```bash
        pip install -r requirements.txt
        ```

## Indítás

Indítsd el a játékot a grafikus felülettel:
```bash
python -m alomvaros_szimulator.main
```
*(Létezik parancssori mód is a `--nogui` kapcsolóval, ha mélyebbre ásnál.)*
